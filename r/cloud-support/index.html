IT, Systems & Cloud

Cloud Support

You keep cloud infrastructure running and help engineers and customers when it misbehaves.

✓No degree needed ◆Second-easiest entry after help desk.

Can I actually do this?

Good no-degree entry, most often reached via a help desk role first.

Who it suits. People who like systems thinking and are comfortable being careful with things that cost money when left running.

Runway. Realistic after help desk experience, or with focused study plus lab evidence.

Coming from another job?

Already working help desk? You are closer to this than you think — it is the most common path into cloud work. Help Desk / IT Support

Also advertised as

  • Cloud Support Associate
  • Cloud Administrator (junior)
  • NOC Technician (cloud duties)

The route

Four stations, in order. Each one is a thing you finish before the next matters.

  1. 1 Station one

    Learn it free

    Only the best few, deliberately. Every one of these is free to use — the pill on each card says exactly what is and isn't free.

    AWS Cloud Quest: Cloud Practitioner

    ✓Free to learn · no certificate

    Game-based official training including 12 hands-on assignments. The training is free; the certificate exam is separate and paid.

  3. 3 Station three

    Prove it

    A certificate says you passed a test. These say you can do the job.

    Free-tier build with a teardown

    Deploy a static site on S3 + CloudFront or Azure Static Web Apps, stay inside the free tier, then document the teardown. Proving you can turn things off is part of the exercise.

    Infrastructure-as-code mini project

    Use Terraform's free tutorial track to deploy a single resource and destroy it cleanly, with the run documented.

    Break-and-fix log

    Deliberately break things in the free tier and repair them. Three dated write-ups.

  4. 4 Station four

    Get hired

    Search these exact titles

    • cloud support
    • junior cloud administrator
    • NOC cloud

    Who hires for this. Cloud consultancies and partners, managed service providers, any company large enough to run its own cloud footprint.

    Target employers decide your certificate, not the other way round. Read the job ads in your area first, then buy the exam that matches them.

    On salary

    We don't publish salary estimates. Numbers copied between blogs drift from reality, and a wrong number costs you real negotiating power. When we have a verified public source, it goes here with its date.
