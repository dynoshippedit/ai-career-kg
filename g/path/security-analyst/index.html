The Security analyst path

You work out what an attacker did, or is doing, and write it up so someone can act. It is the broader analysis role next to the SOC’s shift-based entry point: ATT&CK is the working vocabulary and CISA advisories are the reading diet. It suits people who chase loose ends and can write clearly under time pressure.

How to use this path

Work the groups in order. Each checkpoint is a gate: do not move on until you can do it unaided. The capstone is level 4 — original work, made public, verifiable by a stranger.

Checkpoints

  1. An investigation of a simulated incident written up in ATT&CK vocabulary, with the evidence chain a stranger can re-derive.
  2. A detection rule written and tested against labeled data, with the tuning decisions documented.
  3. A one-page threat brief from a current CISA advisory, written for a non-technical manager.

The capstone

Level 4 — Extend: Published original threat analysis. A technique deep-dive with detection logic and test evidence, or a detection pack derived from a real advisory series — published, sources dated, reproducible. That is the artifact a hiring stranger checks.
